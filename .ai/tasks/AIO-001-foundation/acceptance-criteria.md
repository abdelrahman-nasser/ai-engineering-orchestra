# AIO-001 — Acceptance Criteria

AIO-001 is complete when all of the following are true.

## Foundation

- [ ] `VERSION` defines Orchestra version `0.1.0`.
- [ ] Canonical terminology exists.
- [ ] Core engineering principles exist.
- [ ] Rule and Policy precedence is defined.
- [ ] Project lifecycle concepts are defined.
- [ ] Context loading behavior is defined.
- [ ] Human control behavior is defined.

## Repository Entry Point

- [ ] Root `AGENTS.md` exists.
- [ ] `AGENTS.md` identifies authoritative Sources of Truth.
- [ ] `AGENTS.md` remains concise.
- [ ] `AGENTS.md` preserves Provider independence.

## Project Configuration

- [ ] `.ai/project.yaml` exists.
- [ ] Project identity is defined.
- [ ] Project lifecycle is defined.
- [ ] default Complexity is defined.
- [ ] default Risk is defined.
- [ ] default Execution Mode is defined.
- [ ] basic Human control configuration exists.
- [ ] context strategy is defined.

## Architecture

- [ ] No specific AI model is required by Orchestra Core.
- [ ] No specific AI Provider is required by Orchestra Core.
- [ ] No programming language or application framework is required by Orchestra Core.
- [ ] Later-version features have not been prematurely implemented.

## Quality

- [ ] Terminology is used consistently across foundation documents.
- [ ] Foundation documents do not materially contradict each other.
- [ ] Required Sources of Truth are clearly identifiable.
- [ ] Independent review is performed before AIO-001 is closed.
