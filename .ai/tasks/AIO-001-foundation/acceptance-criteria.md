# AIO-001 — Acceptance Criteria

AIO-001 is complete when all of the following are true.

## Foundation

- [x] `VERSION` defines Orchestra version `0.1.0`.
- [x] Canonical terminology exists.
- [x] Core engineering principles exist.
- [x] Rule and Policy precedence is defined.
- [x] Project lifecycle concepts are defined.
- [x] Context loading behavior is defined.
- [x] Human control behavior is defined.

## Repository Entry Point

- [x] Root `AGENTS.md` exists.
- [x] `AGENTS.md` identifies authoritative Sources of Truth.
- [x] `AGENTS.md` remains concise.
- [x] `AGENTS.md` preserves Provider independence.

## Project Configuration

- [x] `.ai/project.yaml` exists.
- [x] Project identity is defined.
- [x] Project lifecycle is defined.
- [x] default Complexity is defined.
- [x] default Risk is defined.
- [x] default Execution Mode is defined.
- [x] basic Human control configuration exists.
- [x] context strategy is defined.

## Architecture

- [x] No specific AI model is required by Orchestra Core.
- [x] No specific AI Provider is required by Orchestra Core.
- [x] No programming language or application framework is required by Orchestra Core.
- [x] Later-version features have not been prematurely implemented.

## Quality

- [x] Terminology is used consistently across foundation documents.
- [x] Foundation documents do not materially contradict each other.
- [x] Required Sources of Truth are clearly identifiable.
- [x] Independent review is performed before AIO-001 is closed.
