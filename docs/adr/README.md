# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for AI Engineering Orchestra.

An ADR records an explicit architectural decision, its context, rationale, and relevant consequences.

## v0.1 Status

No Architecture Decision Records have been approved yet.

Agents must not treat the absence of an ADR as authorization to invent an architectural decision.

When a Task requires a material architecture decision, the applicable Human approval requirements and Orchestra policies must be followed.

Future ADRs will be stored in this directory as authoritative Sources of Truth for the decisions they describe.
