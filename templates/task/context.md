# EXAMPLE-001 — Context

## Objective

This directory demonstrates the canonical v0.1 AI Engineering Orchestra Task structure.

It is intended as a reusable example for Projects adopting Orchestra.

## Context

A real Task should replace this content with only the background necessary to understand the work.

Useful Task context may include:

- motivation
- existing behavior
- architectural constraints
- relevant history
- known limitations
- compatibility requirements

Context should remain explanatory and must not conflict with structured requirements in `task.yaml`.

## Scope Boundary

This example demonstrates Task structure only.

It does not define application behavior, Provider behavior, Stack Module behavior, or future Orchestra automation.
